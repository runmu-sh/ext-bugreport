# Changelog

## 1.0.0

- First version: the bug report panel for Torchship (`Bug 1`). Write a draft with subject, severity, category and body; it is the same draft the game's `@bug` command edits. See the game's last recorded error (command, room, traceback) and attach it or not. SUBMIT files it in the bug queue, and MY REPORTS lists your last ten reports with their status. Also adds a `[ ⚠ BUG ]` button (hidden while the panel is open), **Report a bug** in ☰ and the palette, a REPORT IT toast when a command of yours errors, and settings `button.show` and `offer.errors`.
